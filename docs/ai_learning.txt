AI 学习助手与材料接口 v1（0.19.2）
=================================

使用入口
练习页 → AI 练习与语料：按已学内容出题、生成例句、解析日文、待确认内容。
学习项详情也可直接生成该项的例句；例句库可进入日文解析。
设置 → AI 服务：手机直连 OpenAI，个人密钥加密保存在 Android Keystore 对应的私有存储。
语料生成默认 gpt-6.1-sol；实时辅导、问答和问题建议使用单独的 tutor_model，默认 gpt-6-luna。
用户已保存的两个模型设置分别保留；缺少配置字段才采用默认，均可自行修改。
生成需要网络并按 API 账户计费；已经保存的材料和练习可离线使用。

密钥配置
应用内可输入个人密钥，也可粘贴 OPENAI_API_KEY= 这一整行；可识别外层引号及复制时的换行。
保存成功前会检查格式和加密存储回读，成功后清空输入框。失败时保留遮罩输入供修改，离开页面时清除。
本机保存成功不代表 API 授权已验证；首次生成时检查授权。已有密钥不回填到界面。
已在电脑安全创建的密钥可通过 USB 导入：
1. 安装新版 APK，在手机的 AI 服务页点击“准备从电脑安全导入”。
2. 手机开启 USB 调试并连接电脑，选择明确的 adb 设备序列号。
3. 在代码仓库运行 .venv/Scripts/python.exe environment/provision_device_ai_key.py --adb <adb.exe绝对路径> --serial <手机序列号>
4. 十分钟内在手机点击“完成安全导入”。此流程用于个人 debug 安装包。
传输中只写入可由该手机解开的加密文件。密钥不放进 APK、学习数据库、学习备份、反馈或 Git。
电脑上已确认的 .env.local 是独立开发副本，不会随 APK 复制；设备完成导入后可自行决定是否保留该副本。
卸载应用/删除设备数据会失去本机密钥；学习备份不会恢复密钥。移除本机密钥不删除学习记录。

按学习进度出题
只从完成首次讲解且实际独立作答过的学习项选择目标；可以选择薄弱目标。
作为已知背景的词义/读法需有独立答对记录，且最近一次有效评分仍是独立成功；近期答错或查看答案会撤出已知背景。
只看过答案、提示后才作答不能充当独立练习证据；纯展示、设备故障不当作遗忘。既有记录和复习安排不改写。
只上传本次选中目标、背景内容和粗略熟悉度，不上传完整学习事件、日期、复习参数。
支持词义、用法、中日区别、阅读理解、语法含义和语法填空选择题；遵循当前启用题型。
AI 返回题目先由本地结构/目标/版本/题型/泄题规则校验，再由用户确认加入独立补充练习队列。
AI 练习保存草稿、反馈和进度，追加不覆盖旧题，同一目标/题型/题干不会重复入队。
这些未经人工逐条审校的补充题暂不改 FSRS 间隔，也不混入正式复习队列。
只允许完整已显示、非读音/非填空的题干朗读；AI 提供的朗读、注音、调号或安全标记均不可信，不予采用。

生成和保留材料
材料草稿保存在 ai_materials_v1 设置中。保留/舍弃支持逐条或整批，决定不可被再次生成覆盖。
保留材料只追加词义/语法/读音规则与共享例句，不代表加入学习计划。
新项需要完整首次学习讲解、适用题型模板、可用前置项及至少十个不同关联例句，才能显式加入学习。
补充例句提案顶部可直接查看目标及实时例数，满十例后可显式加入计划；已加入的项不会重复加入。
十例按不同原句计算；不同ID的相同原句不能虚增。段落重复原句可共用一例，保留所有原文分段定位和关联。
同句若译文或读法冲突则拒绝自动合并，提示分别审核语境；预览内容不能在保留后静默变成另一种译文。
现有项目和例句优先复用；旧假名作为只读引用目标，不再重复建立新课程记忆项。
语义正确性仍须用户审核；结构校验通过不等于日语、翻译和关联已获权威审校。

接口兼容约定
请求 mode 为 questions / examples / analyze，带 request_id、count、topic、source_text、target/scope/catalog。
请求不接受凭据、分数、排程或工具调用字段。一次最多10条（段落解析指最多新增学习项），原文最多4000字符。
问题响应严格为 questions 数组，单题 target_id/revision/kind/prompt/choices/answer/explanation；
新增可空 order_translation 附属字段。新 API 严格 schema 包含此字段，旧快照省略时仍完全兼容。
材料响应严格为 items/example_pack/segments。共享例句沿用 kanamemory-example-pack version 1。
items 使用本次临时ID；本地按 family/domain/title/reading/meaning 建立稳定内容ID，按教学内容生成 revision。
实验语序参考译文不参与 ID 或 revision；排除其所有嵌套位置，旧无字段内容的 revision 逐位不变。
同ID已有内容不可覆写；引用依赖必须存在且无环。实际新项只支持 word 或 grammar；读音规则用 grammar + pronunciation domain。
模板显式提供受支持的题型，不使用未知语法的通用兜底题。无关模板数组留空。
segments 必须以 Unicode codepoint start/end/quote 精确覆盖原文非空白内容，example_id 指向当前例句。
引用独立保存 target_id、例句revision、精确spans、当前项专属提示和解释；重叠引用沿用例句库的选择/反向索引。
保存版本、原文、请求ID、候选内容和逐项决定。重复请求不得覆盖不同内容；保留材料和例句的写入在同一事务中完成。
未来格式升级须显式提升版本或可选字段，不重写已评分内容快照或旧题单。

普通汉译与省略成分
生成规则集中在 natural_translation_policy.NATURAL_TRANSLATION_RULES，例句、首次学习材料及题目中的普通汉译采用自然、清楚的现代简体汉语。
不为保留日语语序而写成生硬直译或文言。忠实保留词义、角色、虚词范围、否定、时体、语气与授受方向；已有汉译只是语境线索，明显错译不能照抄。
日语省略的主语、宾语等，能用自然无主句表达就不补。只有汉语会不清楚且上下文可靠时才补出，可用自然表达或必要的简短括号。
不得凭空补性别、人物关系、所有者、人数、时间等信息；さん不代表男性。不能只因句子短就加“我／你／他”或括号占位。
氏／様也不直接证明性别，旧译里的“先生”或“我们”不是独立依据。同形词需按日语实际义项处理，例如参观指示的順路译“参观路线”。
ということですね等保留推论与确认语气，不能简化成无条件的断言，也不要求所有类似句子套同一种现代套话。
例如：もう食べました。译“已经吃过了。”；只有明确问的是“早饭吃了吗”时，回答まだです。才可译为“还没吃早饭。”。
翻译正文只含译文。语法说明放现有 rule／hint／explanation 等字段，不把“此处是主语”、资料说明或“待核”塞进句子。
已有译文内的教学注、读音或调号应另行保留，不能在自然化时直接丢弃，也不能新造说明。离线批量接口提供 teaching_note；App AI 响应不增加这个字段，沿用已有解释字段。
确实无法判明的关键词义或指代，离线材料走待核通道；现有 AI 响应无待核字段时省略存疑提案，不擅自添加字段或编造确定意思。
新材料先定稿普通 translation，再生成 order_translation，并把最终普通译文逐字写入其 source_translation；不能继续绑定旧草稿，也不能静默把旧参考改绑到新译文。
独立语序参考仍使用另一套激进保序规则，默认折叠。两种规则按字段区分，不能互相覆盖。
没有普通翻译字段的题目仍将 source_translation 留空，不增加字段或把译文放到会泄题的位置；不改动已有快照、ID、revision、评分或复习安排。

实验性语序参考译文（可选 v1 扩展）
example_pack 的每条例句、instruction 和各 question_templates 变体可分别携带 order_translation。
对象严格包含 version:1、status:"experimental"、source_text、source_translation、text 五个字段。
例句以原文及现有普通汉译双重精确绑定；instruction 绑定 example/translation，不改写普通译文。
题目/模板绑定本地确定的完整日文，source_translation 必须为空；填空只在唯一（　）处填入正确答案后绑定。
变形、重排、纠错和造句模板仅在规范答案本身为完整句时使用该句，不能翻译错误题干或任意拼接碎片。
孤立词、混合说明、隐藏听力、无法确定的来源可省略或为 null。字段类型、来源或绑定不合法则拒绝。
默认折叠。题目里的参考只在答后详细页面显示，不放进题干、选项、答案、反馈正文、朗读或注音支持。
此附属字段不参与评分、复习间隔、题目指纹或去重；重启、导出和备份仍保留它。
同 ID/revision/原文/普通译文的旧例句缺少参考时，用户保留或导入的新参考可补齐；已有参考不被替换。
生成规则集中在 order_translation_policy.ORDER_TRANSLATION_RULES：积极寻找保留日语信息顺序和虚词功能的汉语构式。
语义忠实、汉语语法成立是硬界；在此范围内，保原序优先于当代汉语的常见语序和语体。
可用有实际根据的文言、近代汉语、现代书面语或口语规则，不强制现代词汇或现代句法。
优先尝试话题结构、合法宾语前置及复指、所／者等名词化、适用的句末判断；不因不常用而回避合法构式。
不得把所有です套成“是也”：肯定名词判断、否定判断、疑问、形容词和动词谓语必须分别处理。
必须考虑话题/格关系、限制和焦点、否定范围、时态体貌、语气等助词与虚词含义，不逐字凑词。
不能生造汉语、夹入日文助词或混搭不相容的语法，也不能为了前置宾语凭空增加“把／了”、完成义或强调。
只有确无合法且忠实的保序构式时才局部退回常见汉语顺序。普通译文若已达到同等保序程度可相同，不能仅因更顺口而照抄。
改变词汇使其显得古雅本身不是目标。方言或地域构式需谨慎，确保有根据、可理解且语义范围没有变化。

结构示例（示范完整构式，不是机械句尾替换表）
1. 私は常山の趙子龍です。 → 吾，常山赵子龙是也。
2. 彼が昨日買ったのはこの本です。 → 他昨日所买者，此书是也。
3. 私が欲しいのは水だけです。 → 吾所欲者，水而已。
4. これは私の本ではありません。 → 此，非吾之书也。
5. あなたは教師ですか。 → 君，教师乎？
6. 昨日、この本は田中さんだけが読んだ。 → 昨日，此书，唯田中读之。
7. 田中さんしか来なかった。 → 除田中外，无人来。
8. 雨が降ったので、出かけませんでした。 → 雨下了，故未出门。
9. 私は水を飲みます。 → 我饮水。（无上下文许可新的宾语话题，局部退回SVO；不写“我水饮”或“水を饮”。）
生成仍是实验材料，须保留原文和普通译文供对照。新的规则使用新 policy hash 完整生成，不能把旧缓存改标为新规则输出。

AI引用位置的校正边界
若模型给出的start/end与quote不一致，仅当quote在原句中精确且唯一出现时按该唯一位置校正。
不改写原句、引用文字、学习项或解释；多处（含重叠）匹配、不存在、非法类型仍拒绝。
只在provider处理新生成响应时使用；既有提案、手动导入及备份仍严格校验原始位置。
失败请求供反馈使用的错误与候选在附到控件前立即递归脱敏和限长，不先保存原始敏感对象。

后续交互和请求边界
实际响应数量不得超过本次选择；生成例句不能夹带新学习项，每例必须关联选中目标。
段落解析只能包含原文分段对应的例句，额外例句需要单独发起生成。
生成中锁定输入；取消后恢复，迟到结果不会写入。成功返回表单可继续操作，重启后可从“继续上次输入”恢复草稿。
已保存提案但尚未更新表单完成标记的中断，可直接恢复提案而不重复调用API。
选择题提示词要求干扰项在可见语境中不成立，不能依赖隐藏的语域条件；无法可靠出题时允许少生成。
这些规则仍不能代替日语语义审校；关联目前随整条例句保留或舍弃，不支持对同一句逐关联单独决定。
