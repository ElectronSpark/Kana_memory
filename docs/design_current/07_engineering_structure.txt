01 权威与验证状态
本文件是现行设计规范的工程结构章节，细化01的模块职责，不替代02—04的产品、
调度、数据和AI合同。I=生产已接入；V=所列版本和范围已验证；U=证据不足；P=提案。
实现与验证独立。阶段记录中的数量是各次范围，存在重叠，不能相加当独立测试总数。
公开源码不携带私人目标、语料和完整阶段报告；以下通用工程约束仍须遵守。

02 目录与依赖 [I]
保留app/src/kanamemory包布局。app/pyproject.toml维护Briefcase产品配置；根pyproject.toml
和pytest.ini维护开发工具。内容包只有语料/媒体；个人学习数据库、草稿和凭证留在用户区。

  app启动/装配 -> 页面及流程协调 -> 纯规则/展示模型
                              -> 用例服务 -> 查询接口/写事务服务
                              -> 平台接口
  页面 -> UI基础组件 -> Toga、字体及布局适配

app.py负责启动、服务装配和页面协调。新纯规则、展示模型、基础组件不得反向导入App。
纯规则不依赖Toga、SQLite、平台或网络。优先已有明确接口，不增加只有转发作用的层。
domain.py仍混合类型、规划和存储，不冒称已整体拆成纯领域层；保留的启动/政策边有逐项责任。
不按文件行数拆文件，不新增任意Mixin，也不为了形式统一改动既有业务合同。

03 UI、查询、事务及资源所有权 [I]
- ui_theme.py：六个主题常量。ui_components.py：八个无状态控件构造及组合器命名空间。
  App/页面统一模块属性查找，handler由调用方提供；基础组件不持有会话、不揭晓、不写进度。
  answer_hint属于答题协调层；lesson_diagram_ui自己拥有画布。App旧控件别名只供历史维护工具。
- StudyPathSelection/NodeSelectionStatus为纯选择模型；study_path_ui离屏构造树。
  选择计算与绘制分离，提交复核最新数据，不把展示快照当写权限。
- StudyStore.queries与LearningStore.queries提供具名StudyQueries读投影；TeachingQueries
  提供首次教学证据。连接仍由原Store拥有，reader不开连接、不缓存、不创建事务。
  在已有写事务中调用仍观察同一连接未提交行，不以通用DAO拆散跨表操作。
  题型、能力、业务时间显式传入。页面不取得任意SQL执行通道或新增_db/_pending访问。
- StudyStore/LearningStore保留正式写事务、评分和队列所有权；业务时间用app_clock。
  iter_pending_questions保留原完整行过滤和顺序，_pending仅作内部兼容代理。
  pending_course_headers保留诊断预约；session_question_headers含已完成前缀身份，不能混用。
  read_revision/in_transaction封装连接状态；MaterialWorkflow.budget和个人版本服务负责本域查询。
- StudyPathService.read_operation在一次同步动作内复用目录状态、惰性主队列及业务时刻；
  这是有明确生命周期的读取上下文，不是数据库原子快照，也不是长期缓存。
  上下文退出即失效；新动作重读设置、内容、队列。add_entries独立重查后提交。
  counts题面逐行按需解码一次，空目标不规划，已知空队列不重复读。
  原snapshot双会话缓存及revision/data_version/外部竞争检查保持不变。
- ExampleStore.read_operation只在一次同步页面构建中共享学习状态投影；例句卡片、
  单项例句、例句详情与例句库的排序、链接和背景提示使用同一范围。嵌套读取共享外层，
  离开最外层即释放；不能跨await、线程或后续动作持有。返回值深复制，调用方不能污染缓存。
  本连接写入、外部提交及资源refresh使其失效；事务内始终实时读取且不发布缓存，回滚后
  重读。查询前后的数据库token不同则丢弃本次缓存，不能拼接两版投影。
  这不是原子数据库快照或评分/入队权限；不改变熟悉度规则，不长期缓存学习进度。
- ExampleStore.for_item_page在完整实时排序后只复制所选页的例句/引用/提示，返回total与examples。
  for_item作为limit=None兼容入口。预览/分页UI使用新接口；重排、个人版本、关联和总数政策不变。
- kana_routing.current_identities一次解析本次读取的活动/计划身份，未知方向保留原元组；
  与prospective_identities区分，不能提前合并尚未激活能力。后续动作/写入重新解析。
  添加页及首页预览复用该批量结果，active_units原版本校验和事务回滚路径不变。
- course_planning.iter_question_plans可显式接收本次动作刚读取的unit_states；缺省仍实时get_unit。
  首页缺题预览按(content_id,instruction_scope)复用前置结果，一次读取输入设置及曝光时刻；
  question_not_before显式接收now/exposure_times。追加教学scope不能继承旧scope的豁免。
- TutorUIMixin按StudyStore对象身份复用AITutorStore；不共享给其他Store或线程。
  save_chat_draft拥有独立写事务，每键提交。仅数据库原始JSON与本实例已验证/成功提交的
  私有缓存逐字相同才复用历史校验；未知版本完整校验，不单凭revision数字判新旧。
  此入口只改chat_draft/chat_context/revision，仍检查字段、密钥和总大小，不变输入不写。
  缓存仅一份、commit后发布、失败清除；正式snapshot及其他_mutate继续完整验证。
  该Store写入口的连接访问在architecture_policy中单独说明责任，UI没有新增SQL权限。
- practice_worker/backup_worker各在线程内独立创建、关闭SQLite连接。
  取消后旧结果不能覆盖新请求；backup取消须等待回滚/提交及连接关闭。
  后台结果应用前检查请求/页面身份，不跨线程复用控件，不无依据增加线程或常驻缓存。

04 页面恢复与错误边界 [I]
page_restore.py只共享bindings、原控件挂载和token保护的延后滚动，不依赖App、存储或网络。
普通返回和反馈返回各保留标题/chrome/token、assisted、曝光、lane、内容版本、诊断重建、
计时补偿及队列政策。refresh_return先于旧控件挂载；普通checkpoint/清笔画不能误入反馈返回。
feedback_context对真实Pack从margin读取旧padding字段，保留版本1反馈格式和还原信息。

diagnostic_events.py只记录操作码、阶段、异常类别、首次/末次时间和次数；进程内最多64种
事件、每种计数9999。返回副本，不持久化，不接收密钥、路径、正文、回答、提示词或堆栈。
自身失败不能掩盖原操作。用户主动记录的完整反馈另有合同，不能因日志脱敏而丢失还原信息。
吞掉异常并改为提示重试的 UI 处理（掌握度检查计时/音频、多空填空保存/提交、Tutor 建议、
反馈导出后刷新）先调用 record_error；multi_cloze_ui 为此允许导入 diagnostic_events（审计 B7）。
request_outcome.py协调一次可选生成及finish，区分请求/保存/取消/二次落盘失败；不重发，
不管理数据库、权限或UI。控制器各自保留有效性、曝光、计时和清理政策。
提交成功与显示成功分开，刷新失败不能声称保存失败，不能靠重复提交修复UI。
取消尝试结算自己拥有的attempt；落盘失败记录有限诊断并保留恢复路径，不冒称成功。
原生可选日志失败不得阻止播放或结算。

06 不变项与自动守卫 [I；V以实际报告为准]
重构不得改变学习/能力ID、记录格式、正式历史、题面、草稿、排序、到期、评分幂等、题型开关、
防泄题、导航、权限或迁移语义。正式事务不得部分写入，旧回调不得重复评分。
页面浏览曝光与正式评分/队列变化分开比较；课程追加保留未完成题目，前置不重复、不提前解锁。
FSRS参数与辅助证据权重不属于工程重构范围。

tools/check_architecture.py和architecture_policy.json按文件、作用域、符号/访问形态及次数
拒绝新增违例和陈旧豁免，忽略行号变化。覆盖直接导入及常量动态导入，不声称拦截任意动态代码。
豁免需owner/reason/evidence/exit_condition，不整文件放行；migration_debt不算关闭。
当前受控私有访问属于持久化所有者，不是页面新增_db/_pending的先例。
新增模块同时更新结构规范、相应正负例及tools/public_source_files.txt。

验证分层：增量相关轻量测试→阶段契约→有限原生与分发。fake UI不证明原生排版或性能；
测试收集不等于执行；CI配置不等于远端通过；APK静态对齐不证明16KB设备实测。
原生验证在隔离合成数据上执行，构建与模拟器串行、会话有界。没有证据不写V。
新发现单列，不自动扩展固定目标；本轮引入的回归必须修复。
