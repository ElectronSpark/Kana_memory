添加学习内容：四级多选实现契约
对应版本：0.22.13；更新日期：2026-10-28

范围

本页在现有学习路线之上提供“阶段 → 单元 → 小节 → 学习项”四级多选。选择的是原有 entry 身份，不建立另一套记忆卡或复习算法。本文件描述当前实现；原生界面的最终排版与触摸结果以本次打包手测为准。

入口与初始状态

首页、学习路线、课程与假名的完成/等待页、设置中的添加入口统一进入 show_study_path_add，页面标题为“添加学习内容”。“学习下一小节”仍保留一步追加并继续的流程。

普通入口默认预选下一主线小节，展开它的阶段、单元、小节，其余分支保持折叠。单元详情的“选择本单元内容”和小节详情的“选择本节内容”进入同一选择页，并预选该分支尚未加入的学习项。重新从入口打开选择页会创建新的选择状态，不沿用另一历史页面的可变集合。

学习库导航、自由查阅、AI 单项显式加入、单词拼写另练一组继续保持原用途。没有启用学习路线的旧嵌入控制器保留原有入口。

选择与展开

左侧使用原生树形复选框：空框表示未选、横线表示部分选中、勾号表示全选。已经加入的项和整组显示禁用的灰色勾号；没有任何内容的空组显示禁用空框。父节点的图形状态同时计入灰色已加入叶和本次勾选叶，因此部分已加入的组即使清空本次选择也保留横线；父级点击仅操作仍可新增的叶节点。部分选中时点击会选满该父节点可新增的后代，再点取消全部可新增后代。分组显示“已加入 A/T 项 · 可选 N 项”，有勾选时另行显示“本次已选 S 项”；A/T 始终使用叶学习项数，不与阶段/单元的小节数混用。已全部加入的组不显示可选 0 或已选 0/0。复选框本身不加入文字按钮；屏幕阅读器仍可读取状态和对应标题。

点击阶段、单元或小节标题展开/收起下一层，不改变勾选；折叠的分支中已选项继续保留。点击学习项标题打开对应已有详情页，不同时勾选。已加入、在途未评分、初学中和初学完成的项不可再次勾选；取消选择不会从原学习计划移除内容。

假名保留原 content_id 与 script，平假名与片假名可以分别选择。参考内容只加入阅读安排，不创建独立记忆卡。

顶部保留主要汇总、加入按钮和“清空选择”。没有可新增选择时，提交按钮禁用。“按顺序选多节”展开正整数输入和前五节预览，没有每日数量上限。它的“加入勾选”把所选主线小节合并到当前勾选中，不立即入学，不覆盖此前手选项；重复使用不产生重复选择。无效数量只影响该快捷操作，不阻止提交已经勾选的合法项目。

前置预览与提交

预览由 StudyPathService.preview_entries 提供，显示已选数量、自动补充的前置数量以及涉及的小节数。“查看前置内容”可展开具体名称，默认保持收起。主树中的勾选表示用户主动选择，自动补充的前置另行列出；撤销依赖目标后重新计算仍然必要的前置。

依赖按学习项解析，不因选中同一小节的一项而加入无关的同节项或它们的依赖。已加入的项目作为既有内容处理，不追溯追加新版目录才新增的前置。

“加入并继续”提交前重新读取当前状态，剔除期间已经加入的选择，再解析和验证依赖。精确新增项与课程入学在同一保存事务内完成。连点不能重复入学；保留在历史页面中的旧提交按钮也会重新检查资格。保存异常显示错误，未成功提交的选择仍保留供重试。

提交成功后调用原 continue_study_path 恢复学习。原题单、作答草稿、未评分结果、首学检查点和实际复习间隔继续由原服务管理。浏览、勾选、展开、前置预览和反馈采集均不写学习数据。

导航与持久化边界

PAGE_BINDINGS['study_path_add'] 保存页面自己的 StudyPathSelection、展开集合、快捷/前置展开标记、输入框及树/汇总/预览控件。Back 恢复原 PageState 后重新检查已加入状态，保留仍可新增的选择和展开集合，再恢复滚动位置。即使期间打开了另一张选择页，返回旧页也恢复旧页自己的模型和控件。

本轮未把未提交的勾选草稿持久化到磁盘：页内操作和详情返回可保留，关闭或重启应用后不承诺恢复未提交选择。已经显式加入的学习内容、学习记录、未完成题目和复习安排按现有持久化机制保存，重启后继续可用。

反馈与性能边界

选择树根片段记录格式版本、有效/错误状态、selected_entry_ids、prerequisite_entry_ids、expanded_node_ids、visible_node_ids、已选/前置/合计/小节计数，以及快捷和前置区域是否展开。每个当前显示的节点记录节点身份、选择状态、计数、展开状态及 path_display_snapshot。数量快捷另有其输入和前五节预览片段。

只有可见分支创建原生节点控件；折叠后不保留整棵隐藏 widget 树。勾选通常更新现有节点；程序更新复选框时暂时抑制原生 change 回调，并还原原始处理函数，避免重绘误选或多次包装；展开、收起和详情返回重新构建当前可见树。反馈不复制完整目录子树；只有显示的叶节点携带 content_id，批量已选/前置列表保留 entry IDs。维护数据不显示在主要界面。

反馈 collector 继续负责脱敏、字体/布局/滚动/输入信息及完整性标记。单列表上限 2000 项、关联学习进度目标上限 200；当前实现没有新增 ID 分块机制。若用户展开很多分支或未来扩展目录超过捕获限制，导出必须依据 completeness 标记判断是否完整，不能把被截断的维护快照当作全量目录备份。

回归覆盖

现有选择与 UI 回归包括父级半选、跨阶段选择、折叠保留、已加入项排除、数量快捷合并、无效数量、空选择、提交瞬间重验、重复提交、保存失败、详情返回旧页面模型/控件恢复，以及真实目录的前置预览和反馈只读采集。原始数据库快照与草稿对照用于确认浏览/取消不改变学习状态。原生大字号排版、触摸可达性和长列表耗时由打包后的手动验证补充。
