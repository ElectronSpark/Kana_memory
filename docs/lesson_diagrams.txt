学习图解：接口、覆盖与维护规则
2026-10-28

目的和边界

本轮图解是已有讲解的显示层补充。时间、地点、动作过程、角色、
构形、条件、音拍和音高用矢量关系表达；原有例句、解释、限制条件、
学习项 ID、题目、草稿、评分及到期时间不因加入图解而修改。
图解不能把一个具体示例的时序、义项或音高推广为整个形式的唯一规则。
来源链接和审计详情留在维护资料中，不占用学习界面的主要内容区域。

覆盖统计的单位

本地课程共有 524 项：324 个语法项、34 个读音规则、166 个词义项。
444 项有新增矢量图：288 个语法、34 个读音规则、122 个词义项。
80 项保留结构化文字：36 个语法、44 个词义项。每项都有明确理由；
不把仅将一段文字装进方框、或无法增加理解的装饰图算作有效图解。
DIAGRAMS 与 TEXT_ONLY 必须互斥，二者并集必须恰好覆盖 524 个课程 ID。

假名库有 165 条内容记录。每条都检查平假名、片假名两个脚本槽位，
因此是 330 条审核记录。其中 4 个罕见旧片假名没有对应的平假名槽位，
只记录缺失理由，不造字、不生成该脚本 SVG。实际非空脚本身份为
326 个：161 个平假名身份、165 个片假名身份。

既有依赖审计中的 241 是允许出题的脚本身份数，85 是参考身份数；
241 + 85 = 326。247 是可练身份之间的有向前置关系边数，既不是字形数，
也不是图解数。若只按字符字符串去重会得到 323，因为部分长音、加浊
等符号在两个脚本共享相同字符；脚本身份仍必须分开保留。

目前假名审核结果为 220 张现代构形图、96 个保留既有字源图的脚本项、
10 个保留文字的脚本项、4 个无字形槽位。部分现代构形项也沿用已有
字源对照，来源文件会在逐项报告中另列，不能以类别计数推断删掉了它们。

数据接口

lesson_diagrams.py 管理 kanamemory-lesson-diagram / version 1。
三个作者模块显式给出课程 ID 到图解或保留文字理由的映射：
  lesson_diagrams_grammar_a.py
  lesson_diagrams_grammar_b.py
  lesson_diagrams_words_sounds.py

不根据标题关键词、相似汉字或模型猜测自动套用图解。lesson_view 只在
id、revision、family、domain、title、reading、meaning、instruction
与现行作者内容一致时采用对应图解。用户导入、旧快照或改变义项的内容
保留自己的原说明；不能因为 ID 相似就继承新义项的图。返回值深复制，
调用方对显示对象的修改不能反写共享目录。

通用字段：
  kind：图类；label：短标题；nodes：带 text 和可选 detail 的节点。
  caption：必要限制；focus：可选的重点节点索引。
  text_role='study'：作者明确指定的日文学习文本，使用学习字体。
  未指定或 text_role='ui'：指示和解释文字，使用界面字体。
  日文汉字词必须由作者显式标记，不能仅凭是否包含汉字猜测语言。

节点通常为 2～6 个；beats、pitch 可为 2～10 个。优先短标签，将无法
安全压缩的条件留在原有说明中，不删掉语法限制来缩短图。

图类：
  timeline：节点 at 为 0～1 的相对位置；spans 用 start、end、text
    表示区间，可指定 lane；reference 标示观察点；axis 为两端短标签。
    dashed 表示未实现或未确定，不把示意距离解释为实际时长。
  space：relation 为 inside、outside、above、below、beside、between、
    near、at 或 deixis。一般节点依次是对象、参照物、第二参照物。
    between 必须有三个参照节点；deixis 依次为こ、そ、あ对应的指示区。
    抽象的范围用法须写明不是实体地点。action 可写短动作。
  route、flow：明确路径或过程；默认按节点顺序连接，也可给出 edges。
  roles：必须用 edges 明确动作、物品或信息从谁指向谁。
  composition：组合关系；非相邻合流用显式 edges 表达，不能误画成
    一个组成部分先变成另一个组成部分。
  contrast：并列比较，不自动添加因果或时间箭头。
  scale：程度顺序，axis 可注明尺度，不能暗示时间先后。
  branch：用 edges 的 from、to 表示条件关系，支持分流、合流、多层
    有向无环关系；反向边必须保留方向，不能一律把第一个节点画成前提。
  beats：每个节点代表一拍，highlight 可突出有关拍位。
  pitch：每个节点代表一拍；levels 与节点等长，只取 0/1；
    particle_from 可标出助词边界。词汇音高不等于句子语调或重读力度。

edges 可有 text 和 dashed；所有索引必须有效且不能自指。
图类、关系、节点数量、音高数组、时间范围等由 validate_diagram 校验。
改变含义或扩展结构时应先更新格式约定和审计，不依赖渲染器容错掩盖数据错。

假名和字源

kana_diagrams.py 只画现代的大小写、加浊/半浊符号和小假名组合关系。
它不推断汉字字源，也不生成草书的历史中间形态。
既有 96 条字源记录和 144 个 PNG（包含带待核标记的教学参考图）保留
来源、争议和核验状态。源资源与包内资源按清单 SHA-256 对照；新 SVG
不能覆盖这些 PNG，也不能将“现代教学示意”改称有史料依据的演变阶段。

渲染和导出

lesson_diagram_scene.build_scene 生成同一个矢量场景，供 Android 原生
Canvas 与 svg_for_scene 使用。长文字换行、增大字号时增加图高；
窄屏不能为省空间把小假名缩得不可辨认，音高线也不能跨行偷偷续接。
颜色之外保留形状、文字和方向；可访问描述应包含关系而不只有孤立标签。

离线交付目录：
  environment/artifacts/lesson-vectors-20261028/index.html
  environment/artifacts/lesson-vectors-20261028/id-map.json
  environment/artifacts/lesson-vectors-20261028/svg/
  environment/artifacts/lesson-vectors-20261028.svg.zip

SVG 文件名使用稳定 ID 的 SHA-256 前 20 位，完整 ID、文件名和内容哈希
保存在映射中，并检查短哈希冲突。ZIP 白名单只包含 SVG、HTML 索引和
JSON 身份映射，不包含词库、学习数据库、密钥或个人反馈。

审计与复核

运行：
  .venv/Scripts/python.exe -X utf8 tools/audit_lesson_diagrams.py
  .venv/Scripts/python.exe -X utf8 -m pytest tests/test_lesson_diagram_catalogue.py -q --basetemp=.test_runs/lesson-vector-tests

审计输出 environment/lesson-vectors-20261028-audit.json，逐项记录图解或
保留文字的理由、资源哈希、SVG 映射和布局检查。源测试以及工具不打开
真实用户库，而是建立隔离的 StudyStore/LearningStore：包含旧假名复习、
未完成队列和草稿、524 份课程快照、课程草稿及实际 FSRS 到期记录。
渲染前后全表 dump 必须逐字一致。

现有 teaching view 去掉新增 diagram 字段后与已提交版本逐项比较；
新图不能改变既有讲解块。修改语义字段的快照必须回退到其自己的说明。
宽度 320/420、字体倍率 1/2 的全部 2656 个场景检查线宽、文字行框和
图形边界。文字估算边界通过不等于设备字体与整页排版已经通过，仍须
单独检查 Android 原生页面、放大字号及相关交互。发现越界应修渲染或
内容，不能放宽审计边界、删文字或缩小用户选择的字号来让测试通过。

作者复核重点：
  时间关系：过去、现在、未来、观察时点及未确定后续是否准确；
    必要条件不画成充分条件，伴随变化不强加完成先后。
  角色关系：给出/接受、主动/被动、视角和物品流向是否明确。
  空间关系：实体位置与抽象领域、范围是否分清，指示词依说话双方定位。
  读音关系：拍数、长音、促音、拨音、小假名及助词音高边界是否正确；
    不从未知词典调号合成看似精确的整句曲线。
  示例范围：图中的具体义项和现有学习项一致；例外不能因图简洁而消失。

每次变更作者映射、图类或渲染器后重新审计、刷新 SVG/ZIP，并按需要做
设备视觉检查。更改课程材料或复习逻辑是另一个独立改动，不能夹带在
图解维护中。仍无信息增益的项继续保留文字并记录理由。
