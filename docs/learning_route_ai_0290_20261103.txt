一、与历次要求核对的学习路线
现有内容包：712课程项（353词汇、324语法、35读音规则），239个可练假名字形方向，
356小节。所有声明的item/section前置均位于同节或之前，缺失或逆序为0。
阶段词汇/语法数：生活151/14，日常161/137，连贯17/78，阅读12/74，正式12/21。
78条词汇穿插规则已接入；这不等于覆盖全部现代日语或考试要求词量，后期词量尤其偏薄。
声明图正确也不等于每道自然语料都没有隐含词汇难度；本轮不是重新逐句审校全部语料。

实际控制器已连接：
- 小假名/促音/长音/拨音共享规则、单独字形方向、拗音前置及共享规则验证；
  未归因的拗音错误最多另选2项验证，不直接连坐其他拗音。
- 首学讲解与熟悉度选择、自动逐项教学块、前置保护、后续小节/跨单元连续推进。
- 正式词汇与语法穿插；假名阶段单词辅助练习仍仅影响相关假名/规则，不自动建词卡。
- 当前设置重新过滤队列、追加批次去重、已展示草稿保护和未来到期等待。
- 同一知识点识别/提取/应用切换，错误上下文限定，独立覆盖槽避免无限重练旧错。
- 读音题默认罗马音输入；给罗马音选假名时不提供抄写式转换；不要求日文输入法。
- 标记词高亮、必要短提示、读音/填空/听力的注音朗读防泄题；回答后的图形结果及评分。
边界：现有普通假名当前题在被关闭时会清除未评分字迹/草稿；工具词使用停车保留机制。
其他队列与到期不变。本轮未扩改这项既有行为，不能将其描述为所有禁用题均保留原草稿。

二、本轮发现并修复的漏接
1. Tutor只按旧question_templates计数，12858个扩展变体中10393个索引永远不被枚举；
   retention固定前三个变体也漏掉后加语境。现共用practice_candidates，检查背景已独立
   学会后才入池；Tutor按完成数轮转有界窗口，不用墙钟跳题；诊断按已发生观察轮转。
   Tutor最多8候选，优先保留4个知识点及同目标另一题型；独立检查仍锁定1道本地题。
2. 音高kind在名单里但Tutor只接choice/text/reorder。现增加pitch_fill/pitch_identify，
   v1单词/v2整句/v3汉字分词复用同一快照、可逆草稿、控件、判题及图形反馈。
   未完成/无效输入不记结果；不把内部音高答案JSON显示给用户。
3. API遗漏practice中的目标span。现传校验过的公开presentation：target_spans、
   task_family/scaffold、输入单位及听音/读音/音高/填空限制。模型知道标记哪个词；
   不把答案猜出的文字当公开锚点，不通过普通TTS认证声调。
4. 原生9题型不在课程Store范围。现采用独立native引用：每lane最多当前一个合法头题；
   不复制原题、不建新课程卡、不发送整队列、字迹或草稿。网络回来按题目/会话/设置/
   草稿指纹复查，过期候选拒绝；随后走本地主线首学和到期保护，或原单词工具续练。
   只读准备不提前协调开关、不跨lane改共享Store、不越过头题去挑后面的题。
   无当前合法头题时，该类型只报告为本轮无候选；这不是未掌握，也不会因此记错。
5. 追加边界复核发现：原生候选的next若接受explain，可能讲出答案却没有原生assisted记录。
   已同时收窄schema、提示词和响应校验：含原生候选的next整次只允许retrieve，仍可在
   所供课程/原生候选中选择；text为空、question为null。旧缓存回复在显示和写帮助记录
   前也拦截并转本地。纯课程next及主动ask/explain原合同不变；原生接入是选题/续练，
   不是新建一个原生题内讲解通道。修复前5项红灯及修复后42项通过证据均保留，
   未调用真实API、未影响个人学习数据。
   包括旧缓存UI在内的146项复核通过（18.37秒）：
   .test_runs/route290-final/native-exposure-fix/。

三、模型能力目录与执行权限
26种真实类型均进入辅导/生成/留存建议的能力上下文；每种报告enabled与本轮候选可用性。
目录不表示每次都必须考26种，也不授权模型调用录音/识别或修改调度。
- 课程17种：vocab_meaning / vocab_audio_meaning / vocab_reading / vocab_recall /
  vocab_orthography / vocab_usage / vocab_zh_ja_contrast / reading_comprehension /
  listening_comprehension / grammar_meaning / grammar_cloze / grammar_transform /
  grammar_reorder / targeted_correction / controlled_sentence_production /
  pronunciation_rule / pronunciation_application。
- 原生9种：kana_choice / kana_romaji / romaji_kana / romaji_kana_full /
  romaji_handwriting / kana_handwriting / word_kana / word_meaning_kana / word_romaji。
  word_romaji仍以单个假名为单位逐步组成整词；拼写仍用既有规范/同音判题策略。
- 自由生成仍限6类：vocab_meaning/vocab_usage/vocab_zh_ja_contrast/
  reading_comprehension/grammar_meaning/grammar_cloze；未经语义认证的生成题仍是辅助材料。
  其他类型通过现有本地候选调取。手写模型/TTS不可用或题型已关闭时，不给对应可执行引用。
- 留存检查仍只结算原课程能力；原生假名通道通过Tutor续练，不冒充课程诊断或跨写复习事件。
- free_writing_translation/situational_dialogue/pitch_discrimination/shadowing_read_aloud/
  spoken_recall仍为实验命名，未计入已支持类型，不能让模型虚构这些控件。
