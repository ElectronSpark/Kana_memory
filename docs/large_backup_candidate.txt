大历史学习备份候选：隔离交付，2026-10-27

状态与审查入口
（历史候选方案，已合入 0.22.2；现行格式见 docs/design_current/04_data_ai_interfaces.txt。）

格式与限制
小备份仍按原v1–v8格式选择，v1转v2避免快照重复转义的旧兼容路径保留。
超过外层预算时，以 gzip+base64 JSON 封装相同内层数据，没有新增学习表或调度语义。
外层JSON仍64MiB；独立内层128MiB；每份恢复后的单会话快照仍64MiB。
原MAX_BYTES及domain题单预算未改。新增独立BACKUP_EXPANDED_LIMIT。
编码分块送入gzip，不先组装完整超大内层UTF-8；现有全表Python对象仍存在。
解码验证精确字段、类型、版本、编码、sha256及base64；拒绝重复键、多成员、尾随、
截断、CRC错误、嵌套封装和非有限JSON。实际展开按 min(声明长度,独立上限)+1 拦截，
不能只信gzip ISIZE，也不能通过伪造小声明绕过提前停止。之后共用原v1–v8语义校验。
旧App不会识别大封装；只保证小备份保留旧格式和新App读取旧备份。

原子恢复
先完整验证不可变bytes输入，保留原有用户确认。确认后在BEGIN IMMEDIATE内导出原库，
恢复前备份写同目录唯一短.tmp文件，flush/fsync后原子改名为最终.json，再替换学习表。
文件写失败、fsync/rename失败、SQL或commit失败均不替换原学习记录。临时文件不进入
previous_backup列表。SQL失败后可保留已完成的原记录恢复文件。
恢复前导出同样支持封装，因此大当前库可以恢复小旧备份且可再次撤销。
不声称任意SAF云文件提供商具有原子替换或断电持久性保证。

后台与UI连接归属
新 backup_worker.py 使用 asyncio.to_thread，但只传路径、时区和不可变bytes。
每个worker在自己的线程创建/使用/关闭自己的StudyStore；从不传原SQLite连接。
进入计算阶段前保存当前checkpoint，替换为简短忙碌层，暂停定时刷新并递增页面token，
关闭主学习连接形成硬写入屏障。page_view/screen/系统返回/checkpoint有忙碌guard。
已有AI/识别/下载/构题等任务未完成时，暂不启动并提示等待，不因导出而静默丢弃结果。
通过现有busy旗标及应用协程等待链检测在飞工作；没有取消它们。

阶段结束后主线程重开StudyStore/LearningStore，使快照/学习依赖/课程缓存失效。
导出、检查、取消和失败保留原页面对象、未提交控件及持久草稿；只有成功导入清旧题目
视图并回首页。选择文件、用户确认和最终SAF调用仍在UI线程。
取消await并不会终止线程，因此shield等待worker真正回滚/提交并关闭连接后才解除屏障。
恢复在验证后、备份后、插入期间及commit前检查取消；已commit则明确报告已恢复。
重开失败保留忙碌屏障和“退出后重新打开”入口，不让旧页面继续操作关闭连接。
若提交已完成但UI重开失败，提示“记录已恢复”而不是谎称失败/撤销。
忙碌时关闭应用只请求安全取消并暂缓退出；进程被系统直接杀死仍依赖SQLite事务恢复，
本轮尚未做真实Android强杀/低内存测试。

验证
441项唯一合同/回归通过：38项新存储边界与事务、24项新worker/UI、171项原备份与学习
持久性、207项原导航/SAF/设置UI、1项原拒绝无效导入。重复跑的24项原子文件名验证不计数。
原60060题、超过60MiB的v2往返/撤销回归通过。
最初隔离副本缺语料JSON使23项回归报FileNotFoundError；补复制原资源后只重跑这23项，全部通过。
原“超外层上限一定拒绝导出”一项测试按新产品行为改为“外层仍有界，允许封装，内层超限拒绝”；
没有改动普通JSON输入仍64MiB的断言。

真实字节压力样本（非真实用户/非主模拟失败）
从先前合成历史RO复制，使用正常start_session增加两个未评分历史题单，仅构造字节压力。
69,454,093字节内层（66.24MiB）→7,025,937字节封装（6.70MiB）；原版本对此私有样本报64MiB。
候选251卡、14205次假名评分、1471课程、150课程评分、3题单完整规范化表往返相等；
大库→小库→恢复前备份撤销相等；单会话约14.1MiB。未修改源合成库或主模拟。
该报告阶段含用于比较的额外完整对象，Windows过程峰值约864MiB，不是实际App内存上限。

独立工作线程/事件循环大样本实测
同66.24MiB样本真实后台导出11.63秒，50ms心跳171次，最大间隔159ms；检查3.08秒，
心跳29次，最大间隔477ms；业务表未变。检查时整个Windows进程峰值提交约582MiB。
这是Python本地线程与事件循环测量，未包含Android Java String/UTF-8桥或真实UI渲染。
文件小并不消除原语义校验的内存需求，不能直接放宽到更大的展开上限。
