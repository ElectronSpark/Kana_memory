范围
沿用反馈字段核据、整组当前性、图谱结构检查及短事务采纳入口。

reference.explanation / hint.meaning / hint.rule。仅同身份 C1 的明确已核译文与

人工核据仍明确归属于用户审阅，不冒充独立语言学认证。

格式与记录保护
personal_content_version_v1 的 resource 行支持可省略 kind；缺省为 lesson，
旧 lesson 事件的字段和重建内容保持不变。各类资源的活动头按 kind + id 隔离，
保留原字段、累计改稿、前一版本、计划及支持回执。原内容包和词库只读；
完整学习记录、到期、题快照、未完成队列、草稿与原作答不改。
共享例句ID与词库ID可对应同一句，但它们不是同一个修改对象，不凭相同正文串改。

教学读取与原始资料分开
共享例句 get/for_item/搜索/反向引用与影响检查读取当前个人译文或说明。
词库卡片、详情、列表也显示个人译文；搜索在原审校索引之外包含当前个人译文，
使用同一指纹/状态过滤和稳定分页，不重复返回例句。原审校与来源页保留原件。
natural_translation 展示层不得用随包自然译文覆盖明确采纳的个人译文。
个人版本代次变化后，返回学习项/词条/共享或词库例句详情，以及例句列表，
重建只读内容并保留页面标识和滚动位置；答题、输入表单与冻结结果不重建。

get_raw/export_pack 保留原材料；display_pack 只供当前影响检查，不作证据包。
从课程产生 bundled 例句时先还原个人覆盖的原字段，避免把个人说明重新包装
成随包已核说明。添加例句关联与 AI 同身份归一化使用原件，不把 personal_revision
或当前改稿反向写进 shared_examples_v1。编辑页未另改的当前译文不会被再塞进解释。
evidence_pack 排除被替代的共享例句/引用及被修订课程的引用；collect_evidence
还排除被修订课程的旧 instruction，包括未传 ExampleStore 的生产调用。
修改后的个人正文也不自动成为独立依据。核据报告原件保留，当前可用性另行判定。
对旧事实的排除偏保守，不表示已经完成全部消费者的细粒度历史有效性。
