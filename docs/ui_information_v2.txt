KanaMemory 功能扩展：界面与信息层级设计 v2
日期：2026-10-25
状态：设计提案；未修改生产程序，未进行本设计的实际界面验收。
范围：单词、语法、已学内容的 LLM 练习；衔接现有假名学习、单词拼写与保存的学习记录。

一、界面要解决的问题

界面应帮助用户看清“现在做什么、需要回答什么、错在哪里、下一步是什么”。记忆单位、题型和证据影响由学习模型定义；界面不直接展示内部卡片标识、证据权重、模型参数和算法状态。

当前 app.py 中需要调整的信息组织：
1. show_word_detail 把审核说明、罗马音转换规则、语源缺失通则、逐例句署名和出处按钮穿插在读音、词义、例句之间。
2. show_settings 用一整页串联手写模型、语音安装教程、备份与资料，难以找到常用设置。
3. show_practice_setup 同时承担题型、范围、批次、调度策略、服务安装、候选内容状态等任务。
4. 普通选择题重复展示“新一轮更新选项，本轮保持不变”等无需每题阅读的规则。
5. 反馈中重复解释调度权重、短时巩固与证据限制，容易挤压答案和下一步操作。

设计不通过删除证据或弱化数据质量来减少信息。完整来源、审核记录、版本和许可仍须保留，集中放到用户主动打开的资料层。必要的署名按对应材料要求保留。用户必须知道的不确定性仍就地显示一行简短状态。

二、三层信息结构

作答层：题干、必要语境、音频、输入区域、提交、必要提示、简短反馈。
学习层：读法、当前义项、词性、使用条件、例句、容易混淆的区别、字形演变。
资料层：来源、完整证据、审核状态、音标体系的详细说明、版本、许可、模型与算法说明。

词义差别、读法适用的字形、语法接续、语域和会改变答案的用法限定属于学习层，不应与出处一起隐藏。
“同形词不等于同义词”“包含汉字不证明借自汉语”等通则在相关资料入口解释一次，不反复插入每个词条。
不能可靠判分、播放失败、手写模型未就绪等情况属于当前操作状态，需简短可见，不得伪装成学习者答错。

三、导航与首页

底部主导航：今日 / 练习 / 学习库 / 设置。
今日：到期学习、保存队列的继续入口、加入新内容。
练习：用户主动选择的专项练习、现有单词拼写、已学内容应用。
学习库：假名 / 单词 / 语法三个页内分类，附搜索与筛选。
设置：练习偏好、显示、语音与手写、AI 服务、数据、关于。
不按每种题型或每个技术服务增加底部入口。

首页示意：
  今日
  继续学习
  现在可答 8 题
  [继续]

  单词拼写                         继续 · 剩 6 词 >
  [加入新内容]                 [学习安排]
  今日完成 18 题 · 新学 3 项

首页只有一个显著的今日学习主动作。存在可答队列时继续原队列；只有到期记录时准备复习；没有到期和未完成题时引导加入新内容。
保留用户要求的首页“单词拼写”直接入口；存在草稿时显示“继续单词拼写 · 剩 N 词”，否则显示“单词拼写”。不能因增加“练习”标签又将它藏起来。
其他主动专项的未完成队列以简短续练行展示，不把所有尚未开始的模式变成首页大按钮。
“学习记录”可从今日简短概况进入，不另占同等权重的大卡片。

数字规则：
1. “现在可答 N 题”只计算当前题型设置允许、已可作答的实际队列问题。
2. 待到期内容单列，如“另有 4 项将在 15:20 到期”；不得计入立即可答数量。
3. “题”“词”“记忆项”分别标明。一个词逐假名拼写仍是一个词题，不把字符数当词数。
4. 学习记录按记忆单位汇总；不能把同一记忆单位的多个题型当成多个新学内容。
5. 到期时间跨日期时显示日期；时间到后可答状态刷新。检查按钮无新题时必须给出明确反馈。
6. 新增批次只增加本次实际加入的题，不重复累计历史已完成题。

四、加入新内容与练习设置

“加入新内容”与“调整题型”分为两个任务，不再用一张长表单同时解释全部机制。
加入新内容先选假名、单词或语法，再显示分类、学过数量、待首次评分数量、未加入数量与本批数量。
假名类别保留清音、拗音、外来语组合等用户可选范围；平假名/片假名按学习模型分别记录，统计口径需明确。
数量允许用户自行填写；如可用内容不足，显示实际可加入数量，不设无说明的每日新增上限。
已有未完成队列时主动作叫“追加这批”，不能叫容易误解为替换的“重新开始”。

练习偏好默认采用保存的选择，按能力组织题型，不将多个原始 kind 名全部平铺。
可见摘要示例：“选择、拼写、听音；手写已关闭”。点开后逐项启用，必要时展示一个简短操作例子。
关闭某题型立即影响未完成队列；保留对应学习记录和到期时间。重新开启时不当新内容，也不重复生成已完成问题。
只有选择需要声音或手写的方式时，才显示缺失服务的就绪提示和修复入口。
默认不把审核候选、调度模式、固定轮数等技术性选项混入常规新增流程；确有需要时放入“更多设置”。

五、作答页的共同结构

  [小返回] 任务名称                    剩 N 题
  必要语境 / 音频
  题干
  次级动作：显示答案
  输入区或选项
  [提交答案]

任务名称使用“选罗马音”“补全句子”“写出假名”等自然语言，不显示内部题型标识。
每题只显示完成本题必需的信息。不要在题干旁说明题目生成方法、审核流程和记忆权重。
“显示答案”放在题干区域的次级入口，不能放在提交所在的最下方形成误导。
选择题若点击即提交，不再重复一个无意义的提交动作；拼写、排序、自由输入需要明确提交。
内容中的索引与 UI 文案严格区分；UI 日语标签不能因含假名而自动成为内容索引。
题目中查看有关答案的资料算使用提示，保存该状态；不要为每次查看追加确认弹窗。

作答期间隐藏底部导航。系统返回和左上返回功能一致，正在作答时确认返回今日，并保存当前现场。
已保存的等待页、完成页点击回今日直接返回，不重复确认。
进入详情后返回应恢复题干、选项顺序、已选片段、输入、手写笔迹和播放状态，不回到上一道题的旧快照。
首页系统返回不退出应用。

六、答案、纠错与评分

反馈原位显示，不另开弹窗。先给正确答案，再给必要原因与下一步；任何答案结果都有同一个简短“详细”入口。
正确答案速览不随用户点错的选项改变，也不增加多个“查看某某详情”按钮。
单词拼写错误保持紧凑：正常字号显示正确拼写，错误或遗漏位置标红，下面小字显示我的拼写；不要两个大答案卡。
不能只靠红色传递错误；同时用下划线、位置或简短文本区分遗漏/替换，保持可读性。
逐假名选择罗马音时，反馈对应到具体假名片段；不能只比较最终拼接字符串而掩盖错误分段。
纠错说明优先一条最关键原因，进一步解释放到“详细”。

四个现有复习评分保持易触及；常规字号紧凑排列，大字号可用两行。不要让来源和长解释把评分挤走。
查看答案、使用提示或刚看答案后的补练不得展示会误记为独立轻松回忆的成功评分。
声音失败、识别失败、未提交、不可可靠判分不写成遗忘。
普通用户不必每题看到“低权重调整”“证据上限”等文字；在相应练习首次介绍、模式摘要和学习记录的详情中说明。
若某次不计入复习或只接受部分证据，反馈简短说明实际结果，如“本题暂不计入复习”，不要宣称整句所有内容都已掌握。

七、现有单词拼写与正式单词学习的衔接

保留现有“单词拼写”：用单词双向练习假名，相关假名受低权重影响，单词本身不成为独立记忆项。
新增“正式学习单词”：用户主动加入特定义项、读法或用法后，才进入词汇学习模型所定义的记忆管理。
浏览词条、播放读音、完成旧单词拼写均不得自动把该词加入正式学习。
现有拼写队列、草稿、已提交事件和假名复习时间完整保留；扩展功能不重置旧记录。
相同词在两个功能中出现时，界面用当前任务说明区分目的，不给每个词添加重复警告。
如用户在拼写反馈中选择“学习这个词”，打开词条的加入流程，让用户确认具体义项；该动作不改变刚才的拼写证据。
同一次提交对各记忆单位的影响由统一事件记录去重。界面重复打开反馈、旋转/重建、重启恢复不得再次结算。

八、学习库与详情页

学习库顶部统一搜索；页内类别为假名、单词、语法。学习状态筛选与内容分类分开。
假名表继续采用元音横轴、辅音纵轴，全部展示，停用假名单列；点击表格直接进入详情。
其他普通内容索引使用简短预览再进入详情；练习中使用内联预览。避免当前条目的自索引和自引用。

单词详情的默认顺序：
1. 主要词形。
2. 假名读法、罗马音、按设置显示的音高、播放。
3. 当前义项、词性与必要用法限定。
4. 一个代表性例句与译文。
5. “加入学习”或“已在学习”状态。
6. 常见搭配、中日差异、相近词、其他读法与义项。
7. 资料入口。

读法适用的字形、口语/书面语/贬义等限制必须保留在相关学习内容旁。
中日同形词只在相关义项下呈现短对比；借用路径、历史词源、完整字形对应及方言来源进入资料层。
例句默认呈现句子、播放、翻译和必要用法，不逐条堆审核过程与多个出处按钮；完整出处可从该例句的资料入口定位。
没有可靠词义或读法的研究材料以简短状态标识，不能混入默认评分题。

语法详情的默认顺序：
1. 语法形式与当前核心用法。
2. 接续形式。
3. 一至两条有区分力的例句。
4. “加入学习”或“已在学习”。
5. 使用条件、相近形式、更多例句、资料。
例如同一形式的进行、结果状态等不同用法需明确当前学习目标，但不展示内部义项 ID。

九、假名详情与全部读音首屏

小返回、小标题，去掉重复副标题。字形演变优先靠前；浊音/半浊音符号使用普通文字大小，与清音发音紧凑组织。
全部已有读音样本的播放入口直接位于首屏，包括日语、古汉语、普通话、上海话、苏州话、粤语、西南官话等已收录版本；不能要求先滑动、切页或展开。
不同来源或不同读音不为节省空间而合并。短名有歧义时使用编号，点击后显示完整样本名称。
按钮区采用紧凑网格；当前选中样本的注音、注音方式与必要标签放在网格下方，完整来源与音标说明进入资料。
窄屏或大字号时优先保障播放按钮可触及，再调整字形图位置与排列；不以缩小触摸区域或压成不可读文字换取所谓首屏。
小假名、促音、长音符等采用示例发音时，保留简短“示例”标识；历史假名使用现代读法时明确区分，不重复写长段合成语音声明。
没有可用音频的资料不得伪装成可播放按钮。其缺失状态和文字读音放到对应资料中。
现有最多 15 个播放入口是本轮布局测试基线；新增更多样本时需重新验证容量，不能假定原布局无上限适用。

十、已学内容的 LLM 练习

入口名“已学内容应用”，避免让用户先选择模型或填写提示词。
默认页面只需：范围“已学单词与语法”、题型摘要、本组数量、开始。
进一步设置包括主题、具体内容、难度和允许的题型。默认沿用用户现有题型开关。
未学词或新语法不得无提示地成为评分目标。少量必要背景词可以就地释义，不把读题困难误记为目标知识遗忘。
生成前从已学内容与允许题型建立目标集合；题目通过完整性和答案检查后再进入队列。
生成状态提供简短进度与取消；取消、离线、超时或额度不足不影响已有队列和草稿。
存在已缓存题目时可继续；没有题目时给清楚的重试/返回操作，不留下空白页或失效按钮。
练习中不展示模型名、温度、token、JSON、检索日志和完整来源说明。这些在 AI 服务设置与题目资料中查看。
接受多个正确表达时反馈“这也是可接受的表达”；不能可靠判分时不写入遗忘事件，提供报告问题入口。
一次整句评价不能在 UI 中宣称所有涉及的单词、语法和假名都已掌握；只显示学习模型能归因的结果。

十一、设置的信息结构

练习方式：题型选择、输入方式、范围偏好；影响当前未完成题目的行为需在变更后短暂说明。
显示：字号、罗马音显示、音高线、数字调号，后两者可同时开启。
语音与手写：各服务状态、试用、下载/检查；安装教程仅在需要时展开或进入子页。
AI 服务：连接状态、服务配置、用量、发送范围和相关隐私选项。
学习数据：备份、恢复、管理学习内容、删除数据。删除学习数据仍需明确确认。
关于与资料：版本、来源、审核与许可说明。
设置首页不展开所有教程；“重新检查”和“安装”只出现在相关服务页，避免同义操作重复占位。

十二、可测试验收清单

A. 字号与空间
1. 在 Pixel 9 Pro 对应模拟环境和 360×800 dp 窄屏，分别测试 100%、150%、200% 字号。
2. 首页主要动作、单词拼写入口、底部导航名称无截断/重叠；需要换行的文字完整可读。
3. 作答页打开系统键盘后，输入、提交、显示答案三者不混淆；关键按钮可触及。
4. 反馈长义项、长错词和多义答案时，四个评分或适用的下一步操作不被不可关闭区域遮住。
5. 浅色背景下正文、红色错处、禁用状态仍清晰；错误识别不只依赖颜色。
6. 验收要查看实际截图/屏幕，不仅检查控件存在或代码未抛异常。

B. 返回与中断
1. 正在答题时，系统返回和左上返回触发同一确认；取消后答案、选项、笔迹不变。
2. 确认退出后回今日，再进入恢复同一题与草稿；不能回上一题的未答状态。
3. 等待页、完成页返回今日不弹确认；首页系统返回不退出应用。
4. 从答题进入详情并返回不丢草稿，练习及其详情访问过程隐藏底栏。
5. 生成中、音频播放中、识别中返回不让异步结果覆盖已经离开的页面。

C. 队列与数字
1. 在剩五题时退出、追加一批、再次退出追加、重启续练：原题与草稿保留，无重复抽取未评分内容。
2. 首页可答数字等于当前可进入的问题数；待到期另列。到期时刷新后可答数字增加，完成后减少。
3. 每批完成后计数不继续累计历史题；单词逐假名作答不增加词计数。
4. 关闭题型后当前队列跳过不可用问题；再开启仍使用原记录和到期时间，不当新内容、不重复结算。
5. 重复打开反馈、重启恢复、重复点击保存不会重复影响任何记忆单位。
6. 现有单词拼写完成后未自动创建正式单词学习记录；主动加入词汇学习不重置假名记录。

D. 音频首屏
1. 遍历全部假名详情，统计实际可播放样本数，并核对按钮一一对应。
2. 覆盖现有最多 15 个样本页面，在上述屏幕和字号组合下，无滑动、无展开、无切页即可触及全部播放按钮。
3. 每个按钮播放对应样本，选中描述显示正确完整名称、注音和注音方式；不同编号不串音。
4. 无音频项没有假播放按钮；系统语言包缺失给可执行恢复入口，不按播放成功处理。
5. 关闭/离开页面后声音不会误继续或由旧异步回调播放新页面不相关材料。

E. 不泄露答案
1. 罗马音拼假名题显示音高时，不附完整答案假名；音高标注不进入用户答案字符串。
2. 反向题、听音题、语法填空的提示和词义不直接包含目标答案，必要例句不填好空缺。
3. 内容索引打开相关答案资料后记录辅助状态；UI 文案不自动生成内容索引。
4. 显示答案后不出现独立正确回忆的成功评分；恢复草稿保留已查看答案状态。

F. AI 异常与判分
1. 离线、超时、取消、额度不足、返回格式错误、答案缺失都有清晰反馈与重试/返回途径。
2. 失败不丢已保存队列，不扣除题目计数，不记录遗忘，不创建新学习内容。
3. 生成题目遵循已学内容范围和当前题型开关；禁用听音/手写后不出现对应新题。
4. 多个合理答案、无法归因错误、模型判分矛盾进入不确定状态，不强制整句判错并惩罚所有关联项。
5. 缓存题恢复时保留原题版本、顺序、草稿和评分状态，不因重新请求生成而变成另一道题。

G. 信息层级
1. 首次进入词、语法详情可迅速找到读法、当前意思/接续、例句和播放。
2. 默认页面没有逐条长篇来源/审核过程或模型技术细节；资料入口仍能定位到每条具体证据。
3. 对答案有影响的读法限定、语域、义项区别未被移走；不可靠材料没有伪装成已核准事实。
4. 全部旧用户入口的去向可解释，尤其首页单词拼写、备份、手写模型下载和语音安装不能消失。

十三、实施边界

本文件只确定界面信息架构和验收条件，不改变记忆单位、学习事件权重或既有评分结果。
实施需先采用题型目录与记忆模型的最终定义，再制作交互原型验证上述页面状态，随后改生产 UI。
不得以重做界面为理由清空用户学习数据、替换未完成队列、移除原有音频或自动把旧单词练习变成词汇记忆卡。

十四、首次学习的教学页面（根据用户反馈补充）

原设计缺少新增内容进入练习前的教学路径；本节是对学习入口的必要补充。题型目录决定如何练习，不能代替讲解。介绍不是把整张资料详情作为必读弹窗，也不是第一次答错后才显示答案。

1. 进入条件与返回
首次选中一个未引入目标时，自动进入该目标的短介绍。已学目标按原到期安排直接复习，仍可主动回看讲解。介绍、前置补充、引导、独立题分别保存进度；中途退出后首页主按钮可显示“继续学习新内容”。等待和结束直接返回，正在回答时仍使用退出确认。

2. 介绍页
小返回和“初次学习”，接着显示一个内容名称、一句话意思、必要规则及一个完整示例。主按钮是“跟着做一题”。不堆积多义项、所有例外、来源、模型或评分规则。
语法必须同时回答“表达什么”和“怎么组成”；例如给出「読む→読んで＋います」，而不只写一个不了解的“接续：て形”标签。前置知识链接用具体短语，如“还不熟悉て形”，不让用户猜去哪找基础。
假名给现代读音和字形；词汇给当前读法、义项与用法。新项不同能力不必每次重播同一介绍；需要新的前置知识或功能时才补对应内容。

3. 引导页
保留当前规则、给出需要的词形或第一步结果，要求用户完成一个步骤。使用“跟着做”而非考试式标题。答错时原位展示该步骤的正确形成过程，提供再试或回看；不显示 Again/Hard/Good/Easy，也不记作遗忘。
学习过程允许暂停。引导反复失败时回到缺少的基础，而不是无限生成同样选择题，或把点击“懂了”当成掌握证据。

4. 逐步撤去帮助
先穿插其它已学内容，再用不同句子／例子作独立检验。该题隐藏规则但保留非考点词的简短释义，以免词汇困难掩盖语法理解。用户主动回看讲解后保留“参考过讲解”状态；返回题目不能清除此标记，也不能再获得无提示成功评分。
首次独立题按实际能力记录：辨义正确只证明该语法功能的理解，不把应用能力和其它功能一起标为已学。后续才安排接续填空、转换或主动表达。

5. 与日常界面共存
学习库的“学习这一用法／加入学习”进入教学或续学，而不是马上随机出题。批量加入界面仍简洁；按目标逐个介绍，不展示大段全课程说明。首页现在可答题数不包含教学页、引导点击次数；新内容进度可另写“学到一半”，不与复习题数混算。

6. 额外验收
新语法首次打开必须看得到意思、接续、完整例句；未学者不用先答错才能读到说明。
补て形等前置知识后回到原学习进度，不声称已完成全部前置规则。
错误引导、重试、重复查看讲解、退出重启不会生成主／辅助复习评分。
独立题查看讲解后，即使答对也不显示独立成功评级；其状态在退出和重启后仍在。
同一流程重复提交只有一次最终评分；已学习内容回看介绍不重置旧间隔或重新建卡。
正常与200%字号下检查介绍、前置补充、引导错题、独立反馈和完成页，避免解释挤掉主要按钮或被截断。

十五、选择题旁的小喇叭（用户补充）

完整日语题干的词义／语法意义等选择题，在不以读音、音高或补全形式为考点且音频不会揭示正确选项时，把一个小喇叭直接放在日语题干旁。图标视觉尺寸小，但点击区域至少44dp；不另加一行重复的“播放音频”项目，正常状态不常驻长注释。

题目中有空缺、要求选择读音或假名拼写、要求根据音高/语气判断、朗读会消除待考歧义时，不加这个辅助按钮。即使界面是选择题，只要是在选空缺的内容，也属于填空。保持原有听力题的必需音频，不将此规则误解为禁用听力。

播放内容只取经审核的当前可见日语题干，不拼接正确答案、不读中文翻译、不补空、不读取整页文本、隐藏反馈或默认选中的正确选项。题目旁的按钮不能复用“播放完整答案”的音频。LLM 题须通过相同资格检查，不依赖它自称“不会泄题”。

这一辅助播放不等于查看答案，也不自动将视觉题变成听力测验；保存实际播放状态，仍只评价原本声明的目标。播放失败不修改答案、提示状态或评分；仅在点击失败后短提示，并保持可继续作答。换题、返回或提交时停止旧音频，过期回调不改动新页面。

草案中以“今、音楽を聞いています。”的含义选择题示范；只读该日语句子，三个中文选项不进入播放载荷。现有“このいすは（　）です。”、引导填空和罗马音拼写页均不提供辅助题干播放。草案尝试使用浏览器暴露的本地日语语音；没有可用语音时清楚提示，不使用其它语言声音冒充日语。正式 Android 实现继续使用原有经过检查的日语语音服务。

本轮验证：通过本地语音接口替身检查实际提交给朗读器的文本仅为公开日语题干；正确／错误选项、提交后的解析均不改变该文本。覆盖重复播放、离题取消、过期回调、没有本地日语语音、填空／拼写／引导页的过期点击拒绝，以及100%/200%字号和44px点击区域。首次学习20组布局及宿主控件回归通过。此验证不代表已试听实际系统语音或完成 Android 实现。

十六、题干上方的假名注音与调号（用户补充）

日语正文保持原词形；用词或词段对应的 ruby 在上方标假名，旁边紧接小号数字调号。数字表示该词段的调型，不能给整句话随意附一个数字。让注音随正文换行，不另起一大段罗马音、全句假名或来源说明；题干小喇叭仍紧邻正文。

“显示”内提供独立的“假名注音”和“数字调号”开关，可同时开启；已有词条音高线显示保留。开关只改变合格辅助的可见性，不能越过泄题规则。正确答案选项、解析、未公开听力文本不参与注音构造。注音和数字均不进入作答字符串，小喇叭仍仅读取原始公开日语题干。

按题目实例、考点和词段分别检查假名与数字。读法／拼写目标不公开目标读音，音高目标不公开目标调号，听力不新增字幕，填空不补目标词、调号或拍数。只要注音消除了正在考查的歧义，即使题名为“理解”也应隐藏该标注。安全的非目标片段可以保留；无法确定安全性时省略。正式实现细则与29类题型约束见题型目录及记忆模型第6.4节。

草案的语法含义题示例为“今、音楽を聞いています。”：今上方为いま①，音楽上方为おんがく①，聞上方为き。两个数字核对自现有 kanjium 数据；未给聞いています套用聞く的辞书形调号。调号未知不等于0，缺可靠表层读法的项不凭LLM猜测。资料页保留来源与版本，题目旁不重复显示。

显示安全注音不等于查看答案，也不阻止原本的语法理解评分；但看到了读音不构成独立读法、假名识读或听力证据。界面故障泄题或材料错误应进入无效／待确认状态，不扣用户遗忘分。
